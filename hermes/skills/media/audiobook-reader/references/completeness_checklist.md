# 导入后完整性核查清单

每次 `add_book.py` 导入后必须执行的核查项。用户会主动核验工作，不做核查就上报是被反复指出的问题。

## 工具

`scripts/verify_book.py --book "<书名>"` 一次性跑完所有自动检查。
跨版本对比加 `--compare "<另一本>"`。

## 7 项核查

### 1. 总字数 vs 公认基准
对照已知字数（金庸长篇约 80-100 万汉字）。明显偏少 → 可能有章节缺失；明显偏多 → 可能含噪音/重复。

### 2. 章节字数分布
- 默认报警阈值：低于平均 50%
- 异常短不一定是错（如金庸射雕第33回"来日大难"本身就短，10K 字）
- 关键是**与同书其他章节相比**异常，不是绝对值

### 3. 末段完整性
每章末段以 `。！？"…` 收尾才正常。否则两种可能：
- HTML 噪音残留（如站名/作者署名）
- 正文被截断

修复：找出共同噪音模式，加进 crawler 的 `skip_keywords`，重爬。

### 4. 章节标题计数
对照预期章节数：
- 金庸三联修订版：40 回 + 后记 + 附录×2 = 43
- 金庸新修版：通常和修订版一致（40 回），如果显示 41 → 检查 mobi 重复章节 bug

### 5. 重复章节侦测（**mobi 解析常见坑**）
检测相邻章节标题首 8 字是否相同。曾经实测：
- 苦瓜书盘下载的射雕新修版 mobi，第 38 章实际是第 37 章的重复条目
- 章节总数虚高，但不影响阅读
- mobi 元数据问题，非 parser bug

### 6. HTML 噪音残留扫描
关键词：`版权 / 本站 / 官网 / Copyright / 免责声明 / 请记住 / 一秒钟 / 推荐顺序`
扫描位置：每章末 200 字（噪音通常在尾部）

### 7. 跨版本字数对比
同书多版（如金庸的修订版 vs 新修版）应同回字数差在 ±10% 以内。
- 差 > 30% → 报警，**一般是真实版本差异**（金庸新修版补叙了很多内容）
- 同回但回目名不同 → 是金庸改写时改了名（如修订版"冤家聚头" → 新修版"往事如烟"）

## 对外回报模板（QQ Bot 用 markdown 表格更清晰）

```
📊 <书名> 完整性核查

✅ 数据正常:
- 章节数 43（预期 43）
- 汉字数 779,866（基准 80 万 ✓）
- 末段收尾 40/40 完整
- 关键人物频次合理（郭靖 5000 / 黄蓉 3647）

⚠️ 已知小问题:
- 每章末尾有孤立"金庸"署名残留（40 处），念到末段会多读 2 字
  修复成本：crawler 加 skip_keyword 重导入

结论: ✅ 可用 / 🔧 需修复 / ❌ 数据缺失
```

## 跨版本对比已知差异（金庸）

| 现象 | 是真实差异 | 是 bug |
|------|----------|--------|
| 同回字数差 < 10% | 异文修订 | - |
| 同回字数差 30-60% | 新修版补叙 | - |
| 同回回目名不同 | 金庸改写重命名 | - |
| 同版相邻两章标题完全一样 | - | mobi 解析重复 |
| 某章字数为 0 或极少 | - | 解析失败/反爬截断 |
| 总章数与公认数差 1+ | 看情况 | 多数是 parser 误切或漏切 |
