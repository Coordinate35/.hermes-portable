## 卢麒元投资分析框架（整合版V3）

### 一、核心理论体系

**1. 资本流转三流理论**
- 流向：资本流动的方向（由息差、资本利得、汇率预期决定）
- 流量：资本流动的规模
- 流速：资本流转的速度（M×V=P×Q，费雪方程式）

**2. 货币三层次理论**
- 纸币：政府/机构发行的可交易有价证券总和
- 通货：流通中的货币（马克思定义）
- 资本：处于投资中的货币

**3. 周期理论**
- 康波周期（技术革命周期，约50-60年）
- 朱格拉周期（设备投资周期，约10年）
- 基钦周期（库存周期，约3-4年）
- 季耶夫周期（房地产周期，约20年）

### 二、核心投资策略

**1. "短股长金"策略**
- 长期（5-10年）：持有黄金等贵金属
- 短期（波段操作）：不超过30%资金用于股票
- 核心逻辑：货币贬值趋势下的保值策略

**2. 右派投资法（右脚右肩理论）**
- 不在左脚买入（抄底），在右脚确认后进入
- 不在左肩卖出，在右肩确认后退出
- 不追求完美的高低点，追求确定性

**3. 资金配置原则（三三四原则）**
- 30%：长期投资仓位（黄金等）
- 30%：短期操作仓位（股票等）
- 40%：现金预备队（用于律动操作）

**4. MACD"一板斧"技术**
- 核心指标：MACD金叉买入、死叉卖出
- 纪律：严格按信号执行，不预测
- 周期：月线、周线、日线结合判断

### 三、真实通胀率计算体系

**1. 公式1：货币供应量法（推荐）**
```
真实通胀率 = CPI + (M2增速 - GDP增速)
```
核心逻辑：官方CPI严重低估真实通胀，必须纳入货币超发程度

**2. 公式2：资产配置法**
```
真实通胀率 = 60%×CPI + 20%×房价涨幅 + 20%×股市涨幅
```
权重分配：CPI(60%) + 房价(20%) + 股价(20%)

**3. 实质利率计算**
```
实质利率 = 名义利率 - 真实通胀率
实质负利率 = 真实通胀率 - 名义利率
```

**临界点判断：**
- 实质负利率 > 10%：进入两位数，避险信号
- 实质负利率 > 12-15%：极高风险区

### 四、四矩阵决策框架

基于经济增长和通胀水平两个维度：

| 状态 | 经济增长 | 通胀水平 | 实质负利率 | 投资策略 |
|:---:|:---:|:---:|:---:|:---:|
| **高高** | 高增长 | 高通胀 | 极高(10-15%+) | 🏠房地产（不二选择） |
| **低高** | 低增长 | 高通胀 | 极高 | 🥇黄金（避险首选） |
| **高低** | 高增长 | 低通胀 | 低/正 | 📈股票/实体经济 |
| **低低** | 低增长 | 低通胀 | 较低 | 💰现金/债券 |

### 五、实战使用流程

```
Step 1: 获取数据（名义利率、CPI、M2、GDP、房价/股价）
Step 2: 计算真实通胀率 = CPI + (M2 - GDP)
Step 3: 计算实质利率 = 名义利率 - 真实通胀率
Step 4: 判断周期位置（高增长/低增长 + 高通胀/低通胀）
Step 5: 根据四矩阵确定资产配置
```

### 六、历史参考数据

**中国2008-2018年：**
- 实质负利率：始终>5%，最高10-15%
- 名义贷款利率：4-5%
- 实质通胀（还原后）：未低过5%

### 七、核心结论

1. **CPI是骗局**：官方CPI严重低估真实通胀水平
2. **货币是关键**：必须考虑M2增速和货币超发程度
3. **资产配置决定命运**：不同周期配置不同资产
4. **黄金是最后防线**：滞胀/高通胀环境下，黄金是保值首选
