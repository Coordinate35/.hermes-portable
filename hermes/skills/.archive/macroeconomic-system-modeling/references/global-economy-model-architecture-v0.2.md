## 一、今日核心结论

1. 全球财富不可凭空创造：任何经济交互只能是存量转移。全球净财富的唯一来源是实体资本净积累（净投资），金融交易（借贷、汇兑、股权交易）不改变全球净财富。
2. 名义记账不可加总：在没有统一会计单位的系统中，"全球财富总和"是伪概念。必须引入不可稀释的实物锚（Numéraire）。
3. 实物锚 = 标准商品篮子：以固定物理构成的全球可贸易商品篮子作为记账单位 Ω，所有资产/负债/交易统一折算为"等效篮子数"。
4. 实体资本免疫名义贬值：采用重置成本法，实体资本以本国篮子价格折算后，本币超发（通胀）不改变其 Ω 价值。贬值仅体现为持有现金者的购买力蒸发。
5. 汇率内生：两国汇率由购买力平价自然导出——即两国购买同一标准篮子的本币成本之比。

## 三、概念定义表

| 概念 | 符号 | 定义 | 所在层 | 守恒属性 |
|:---|:---:|:---|:---:|:---:|
| **标准商品篮子** | Ω | 固定物理构成的可贸易商品组合，作为全局不可稀释记账单位 | Layer 0 | 物理构成恒定 |
| **篮子价格** | B_i(t) | 在经济体 i 购买一整个标准篮子的本币成本 | Layer 0 | 随通胀/汇率波动 |
| **实体资本** | K_i | 经济体 i 拥有的生产性实物资产 | Layer 1 | 质量守恒，价值按重置成本折算 |
| **存货** | I_i | 持有的可贸易商品库存 | Layer 1 | 物质守恒 |
| **贸易流矩阵** | T_{ij,m} | 经济体 i 向 j 出口商品 m 的实物量 | Layer 1 | Σ_i T_{ij} + E_j = Σ_i T_{ji} + D_j + ΔS_j |
| **本币现金** | M_i | 经济体 i 持有的基础货币 | Layer 2 | ΣM_i = M̄（封闭系统） |
| **金融资产** | A_i | 持有的他国债券和股权 | Layer 2 | 债权=债务（全球净额为零） |
| **金融负债** | L_i | 欠他国的债务 | Layer 2 | 同上 |
| **资金流矩阵** | F_{ij} | 从 i 到 j 的净资本流动 | Layer 2 | Σ_i F_{ij} = 0 |
| **名义净财富** | W_i^{nom} | 以本币计价的资产减负债 | Layer 2 | 不可加总 |
| **实际净财富** | W_i^* | 以 Ω 计价的资产减负债 | 跨层 | ΣW_i^* = ΣK_i^* + I_i^*（金融净额抵消） |
| **汇率** | e_{ij} | 本币 i 对本币 j 的兑换比率 | 跨层 | e_{ij} = B_i / B_j（PPP基准） |
| **重置成本** | RC_{if} | 在 i 国重建 1 单位 f 类型资本所需的篮子数 | Layer 1→0 | 随技术/效率变化，不随货币超发变化 |

## 四、核心数学关系

### 4.1 全球财富守恒

$$\sum_{i=1}^{N} W_i^*(t) = \sum_{i=1}^{N} \left( K_i^*(t) + I_i^*(t) \right)$$

全球实际净财富严格等于全球实体资本与存货之和。金融债权债务在全球加总时完全抵消。

### 4.2 实体资本 Ω 估值

$$K_i^* = \sum_{f} Q_{if} \cdot \frac{\sum_{m} a_{fm} \cdot P_{im}(t)}{B_i(t)}$$

### 4.3 金融资产负债折算

$$A_i^* = \sum_{j} \frac{V_{ij}^{(j)}}{B_j(t)}, \quad L_i^* = \sum_{j} \frac{D_{ij}^{(j)}}{B_j(t)}$$

### 4.4 汇率内生

$$e_{ij}(t) = \frac{B_i(t)}{B_j(t)}$$

### 4.5 每期状态转移

$$\begin{aligned}
K_i^*(t+1) &= (1-\delta)K_i^*(t) + I_i^*(t) \\
M_i^*(t+1) &= M_i^*(t) + \sum_j T_{ji}^* - \sum_j T_{ij}^* + \sum_j F_{ji}^* - \sum_j F_{ij}^* + \Delta M_i^{mint} \\
W_i^*(t+1) &= K_i^*(t+1) + M_i^*(t+1) + A_i^*(t+1) - L_i^*(t+1)
\end{aligned}$$

### 4.6 全局约束检查

```python
assert abs(sum(M_star) - M_bar_star) < epsilon
assert abs(sum(sum(A_star)) - sum(sum(L_star))) < epsilon
assert abs(sum(W_star) - sum(K_star + I_star)) < epsilon
```

## 五、偏离观测与回归优先级

### 5.1 三种偏离类型

| 类型 | 定义 | 关键指标 |
|:---|:---|:---|
| 绝对偏离 | 单一资产市场价格 vs 重置成本 | P/Replacement Cost |
| 相对偏离 | 两种资产市场比价 vs Ω成本比 | 金油比、铜金比、房价收入比 |
| 跨国偏离 | 市场汇率 vs 购买力平价汇率 | e_market / (B_i/B_j) - 1 |

### 5.2 四锚定法

| 锚 | 公式 | 核心功能 |
|:---|:---|:---|
| 成本锚 | 市场价格 / (Ω重置成本 × B_i) | 免疫货币幻觉 |
| 收益率锚 | 预期现金流(Ω计) / 价格(Ω计) | 捕捉"熬不住"的资产 |
| 货币锚 | (M_i/B_i) / K_i^* | 货币稀释实体财富的程度 |
| 跨国套利锚 | [P_im/B_i] / [P_jm/B_j] - 1 | 识别贸易壁垒与汇率操纵 |

### 5.3 RPI回归压力指数

$$RPI_i = \frac{\text{套利硬度}_i \times \text{现金流约束}_i \times \text{融资依赖度}_i}{\text{制度保护厚度}_i}$$

$RPI$ 越高，越可能率先回归。

| 优先级 | 特征 | 典型场景 | 预期时间 |
|:---:|:---|:---|:---:|
| P0 | 高套利+高融资+无保护 | 跨市场同资产价差、高杠杆逼仓 | 天-周 |
| P1 | 高现金流燃烧+中融资 | 亏损企业股权、空置商业地产 | 月-季 |
| P2 | 低套利但高融资 | 城投债、房地产开发商 | 季-2年 |
| P3 | 低套利+低现金+有保护 | 一线房产、主权货币 | 2-10年 |
| P4 | 负现金+制度硬撑 | 日本国债、僵尸国企 | 十年+ |

### 5.4 反直觉洞察
> 最先回归的偏离，往往不是偏离度最大的那个。
> 2008年：房地产偏离61%，CDO/CDS偏离30x。但CDO/CDS有每日盯市+保证金追缴的极硬约束，RPI更高，先崩（周级）。

## 六、当前存在的问题

### 6.1 未闭环问题
1. 生产函数未定义（Y_i = f(K_i, L_i, A_i)）
2. 货币创造机制未建模（央行/商业银行四重记账）
3. 消费/储蓄决策未建模
4. 汇率偏离PPP机制未建模
5. 劳动力/人口未纳入
6. 技术进步未建模
7. 政府/税收/转移支付未分离
8. 危机/非线性/断裂处理

### 6.2 数据落地困难
1. 实体资本重置成本系数 $a_{fm}$ —— 需 EXIOBASE/投入产出表
2. 各国商品到岸价 $P_{im}(t)$ —— 需统一为到岸价
3. 资本存量物理数量 $Q_{if}$ —— Penn World Table/各国统计局
4. 跨境资产负债货币面值 —— IMF CPIS / BIS
5. 篮子权重基年确定 —— IEA/USGS/FAO/World Steel
6. 非贸易品处理 —— 房地产/本地服务/建筑业
7. 人力资本量化 —— 教育/健康/技能溢价

### 6.3 建模争议
1. 黄金是否纳入篮子（倾向于≤5%）
2. 篮子权重：价值权重 vs 实物权重（倾向基年价值权重）
3. 篮子更新频率（5年/10年/永不变）
4. 实体资本折旧率 δ 分层
5. 股权估值：市值法 vs 成本法
6. 环境/碳作为负资本
