# 宏观经济系统建模 —— 多经济体财富守恒框架

## 一、触发条件

当用户涉及以下任一主题时加载本 skill：
- 建立多个国家/经济体的交互经济模型
- 财富守恒、不能凭空创造财富
- 存量流量一致模型(Stock-Flow Consistent, SFC)
- 实物锚/商品篮子作为记账单位
- 价格与价值的偏离观测
- 判断多个偏离中哪个先回归
- 汇率内生/购买力平价建模

## 二、核心设计原则

### 2.1 铁律
1. **全球财富不可凭空创造**：任何经济交互只能是存量转移。全球净财富的唯一来源是实体资本净积累（净投资）。
2. **名义记账不可加总**：在没有统一会计单位的系统中，"全球财富总和"是伪概念。必须引入不可稀释的实物锚。
3. **金融资产负债全球净额为零**：Σ(全球净金融资产) ≡ 0。
4. **货币总量守恒**：封闭系统中 ΣM_i = M̄。

### 2.2 两层分离
- **实体层(Layer 1)**：物质/能量严格守恒（质量不灭）。实体资本用重置成本法估值。
- **金融层(Layer 2)**：不守恒，但满足会计恒等式。金融交易只是财富分配凭证。

## 三、分层架构

```
Layer 3: 政策/制度层  —— 货币/财政/贸易政策驱动扰动
    ↓
Layer 2: 金融/货币层  —— 资金流矩阵 F_{ij}，会计恒等式守恒
    ↕ 映射（价格 P_{im}，汇率 e_{ij}）
Layer 1: 实体/物理层  —— 贸易流矩阵 T_{ij,m}，物质严格守恒
    ↕ 估值映射（以标准商品篮子为锚）
Layer 0: 记账锚定层   —— 标准商品篮子 Ω（Numéraire）
```

## 四、实物锚（Numéraire）设计

### 4.1 标准商品篮子
选定一篮子全球可贸易核心商品，固定物理构成后锁定：

| 商品 | 篮子中的数量 | 权重逻辑 |
|:---|:---:|:---|
| 原油 | 50 桶 | 全球能源资本核心，占运营成本约30% |
| 天然气 | 3000 立方米 | 工业和电力关键过渡能源 |
| 铜 | 0.3 吨 | 电气化/新能源核心金属 |
| 钢材 | 1.5 吨 | 资本形成直接投入 |
| 水泥 | 3 吨 | 房地产和基建不可替代 |
| 铝 | 0.2 吨 | 轻工业和电力传输 |
| 小麦 | 1 吨 | 劳动力再生产社会基础 |
| 黄金 | 3 克 | 跨期财富储存和金融避险 |

### 4.2 篮子价格
$$B_i(t) = \sum_{m} P_{im}(t) \times b_m$$
即在经济体 i 购买一整个标准篮子的本币成本。

### 4.3 折算规则
- 本币项目 ÷ B_i(t)
- 外币项目 ÷ B_j(t)
- **什么货币计价，就用哪个经济体的篮子价格除**

### 4.4 汇率内生
$$e_{ij}(t) = \frac{B_i(t)}{B_j(t)}$$
市场汇率可在此基础上叠加资本流动溢价、风险溢价、政策偏离项。

## 五、核心数学关系

### 5.1 全球财富守恒（铁律）
$$\boxed{\sum_{i=1}^{N} W_i^*(t) = \sum_{i=1}^{N} \left( K_i^*(t) + I_i^*(t) \right)}$$

全球实际净财富严格等于全球实体资本与存货之和。金融债权债务在全球加总时完全抵消。

### 5.2 实体资本 Ω 估值（重置成本法）
$$K_i^* = \sum_{f} Q_{if} \cdot \frac{\sum_{m} a_{fm} \cdot P_{im}(t)}{B_i(t)}$$

分子为重建本币成本，分母为篮子本币价格，比值为**重建所需篮子数**。本币贬值时分子分母同比例变化，Ω 价值**纹丝不动**。

### 5.3 金融资产负债折算
$$A_i^* = \sum_{j} \frac{V_{ij}^{(j)}}{B_j(t)}, \quad L_i^* = \sum_{j} \frac{D_{ij}^{(j)}}{B_j(t)}$$

### 5.4 每期迭代后全局约束检查
```python
assert abs(sum(M_star) - M_bar_star) < epsilon          # 货币总量守恒
assert abs(sum(sum(A_star)) - sum(sum(L_star))) < epsilon  # 债权=债务
assert abs(sum(W_star) - sum(K_star + I_star)) < epsilon   # 财富恒等式
```

## 六、偏离观测与回归优先级

### 6.1 价格与价值的严格区分

| 维度 | 价值(Value) | 价格(Price) |
|:---|:---|:---|
| 定义 | 以Ω计量的重建成本或长期均衡生产成本 | 以法币计量的市场交易价格 |
| 所在层 | Layer 1（实体/物理层） | Layer 2-3（金融/货币层） |
| 稳定性 | 技术、资源禀赋、供应链决定，变化缓慢 | 货币供应、杠杆、预期、情绪驱动，波动剧烈 |
| 是否可稀释 | 不可被央行印钞稀释 | 可直接被法币超发扭曲 |

### 6.2 三种偏离类型

**类型A：绝对偏离**（单一资产）
$$\text{Price-to-Replacement-Cost} = \frac{\text{市场价格（本币）}}{\text{重建同规格资产的本币成本}}$$
- > 1.3：泡沫/货币幻觉
- < 0.7：低估或技术淘汰

**类型B：相对偏离**（资产间比价）
- 金油比、铜金比、房价收入比、股市市值/GDP、M2/实体资本

**类型C：跨国偏离**（汇率vs PPP）
$$\text{Deviation}_{FX} = \frac{e_{ij}^{market}}{B_i/B_j} - 1$$

### 6.3 四锚定监测法

| 锚 | 公式 | 适用 | 核心功能 |
|:---|:---|:---|:---|
| **成本锚** | 市场价格 / (Ω重置成本 × B_i) | 房地产、基建、大宗商品 | 最直接，免疫货币幻觉 |
| **收益率锚** | 预期现金流(Ω计) / 价格(Ω计) | 股票、房产、债券 | 捕捉"熬不住"的负现金流资产 |
| **货币锚** | (M_i/B_i) / K_i^* | 全体经济 | 货币稀释实体财富的程度 |
| **跨国套利锚** | [P_{im}/B_i] / [P_{jm}/B_j] - 1 | 可贸易商品 | 识别贸易壁垒与汇率操纵 |

### 6.4 回归优先级判别——RPI指数

**核心规律：回归速度由"约束条件的硬度"决定。**

$$\boxed{RPI_i = \frac{\text{套利硬度}_i \times \text{现金流约束}_i \times \text{融资依赖度}_i}{\text{制度保护厚度}_i}}$$

$RPI$ 越高，越可能率先回归。

| 优先级 | 特征 | 典型场景 | 预期时间 |
|:---:|:---|:---|:---:|
| P0 | 高套利+高融资依赖+无制度保护 | 跨市场同资产价差、高杠杆期货逼仓 | 天-周 |
| P1 | 高现金流燃烧+中等融资依赖 | 亏损企业股权、空置商业地产 | 月-季 |
| P2 | 低套利但高融资依赖 | 地方城投债、房地产开发商 | 季-2年 |
| P3 | 低套利+低现金流燃烧+有制度保护 | 一线城市核心房产、主权货币 | 2-10年 |
| P4 | 负现金流但被制度硬撑 | 日本国债（负利率）、僵尸国企 | 十年+ |

### 6.5 反直觉洞察
> **最先回归的偏离，往往不是偏离度最大的那个。**
> 
> 2008年危机前：房地产偏离61%，CDO/CDS偏离30倍。但CDO/CDS有每日盯市+保证金追缴的极硬约束，RPI更高，反而先崩（周级）→ 房地产后崩（月-年级）。
