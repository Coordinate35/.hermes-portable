# 资本三流动态建模：流量 / 流向 / 流速

把卢麒元「三流」从定性叙事落成**可标定、可证伪**的方程，输出：开关条件 + 时间窗口 + 观测锚。适用于中美/跨境资本流向、外资何时回流、利差与汇率哪个先动这类问题。

## When to Use（触发条件）
- “推到/建一个三流模型”“资本流向的数学模型”“流向逆转的开关”“什么时候逆转/回流”
- 用利差、汇率、股债规模讨论资本流向，需要给出可检验的阈值或时间窗
- 卢麒元框架下把定性判断转成定量结论

## 输出要求（用户偏好，硬性）
1. **必须展开推导**：公式 → 代入值 → 中间量 → 结果 → 判断，不能只给结论。
2. **每个数字带出处与时间**（官方/FRED/交易所），预测与假设单列，不得混入实测。
3. **口径冲突要并列**：卢氏真实通胀与官方 CPI 口径可能差 2–3pp 并给出相反结论，两套都写，标明用哪套下的判断。
4. **时间窗给区间不给单点**：写“基准 2028Q3–2029Q1 ± 2 季度”，并给出使窗口提前/推迟的可观测条件。
5. 长文落到 `~/hermes_data/macro/` 的 md，聊天里给结论 + 关键数字 + 路径。

## 模型骨架

```
dM/dt = g_M·M                    # 流量
dx/dt = v_t·[σ(β·Ω_t) − x_t]     # 流向，σ(z)=1/(1+e^−z)
v_t   = v_0·u_t·(1+κ·T_t)         # 流速，T=换手率，u=政策阀门
F_t   = M_t·dx/dt                 # 净流入
```

**开关的解析解**（关键，别写成 Ω=0）：

```
F=0 ⟺ σ(βΩ*) = x ⟹ Ω* = (1/β)·ln[x/(1−x)]
```

中国资产被全球低配（x 小）→ Ω* 显著为负；两类资产 x 与 ρ 不同 → 股票与债券的开关位置不同，可同时出现“股票流入、债券流出”。

**主开关在居民端**（对外证券投资通常远大于外资来华）：

```
Φ_r = (r_us − r_cn) − E[Δs] − ρ_r      # >0 继续流出中国
```

## 执行步骤
1. 定存量与权重：用股债规模（股票总市值＋债券存量）定 M 与资产类别权重。
2. 算真实通胀：`π = CPI + (M2 − GDP)`；中国用官方同比，美国同时算名义 GDP 与实际 GDP 两套。
3. 算实际利率与名义利差：中美 10Y，同一时点同一来源。
4. 取汇率预期：1Y 远期/NDF 隐含优先，其次 12 个月分析师预测；写明来源。
5. 算 Φ_r 与各资产 Ω_k，与**分项流量**对照校准（外资股本 vs 外资债券 vs 居民对外）。
6. 写情景表解 Φ(t*)=0，给时间窗与触发条件。

## 陷阱
- **BOP 恒等式会骗人**：CA + FA ≈ ΔR，净额只是镜像；判断逆转必须拆 gross flows（外资来华 vs 居民对外），否则会把“经常账户顺差”误读成“资本流入”。
- **口径决定结论**：卢氏口径与官方 CPI 口径可差 2–3pp，足以翻转“已逆转/未逆转”。
- **政策阀门 ≠ 价格开关**：外汇存款准备金率、远期售汇风险准备金、QDII/互联互通额度改变的是流速 u，不是 Φ；开关打开≠水立刻流进来。
- **信用事件是跳变**：美元信用/美债拍卖失败使 ρ_us 跳升，流向不经过零直接翻转；只给触发条件，不给日历时间。
- **区分一阶与二阶**：外资持股边际回升（二阶）≠ 净流入转正（一阶）；结论分层写“边际逆转 / 净流入转正 / 存量再配置”。
- 不要用单月数据定开关；至少用季度 BOP + 月度持仓/利差交叉验证。

## 数据源
- FRED 序列 CSV（免 key）：`curl -s https://fred.stlouisfed.org/graph/fredgraph.csv?id=M2SL`，同理 `GDP`。
- 中美 10Y：中国金融信息网/新华财经（中债）、美国财政部/FRED（美债）、MacroMicro（利差）。
- 国际收支、对外证券投资：SAFE 季度初步数、年度《国际收支报告》。
- 外资持仓：央行上海总部、债券通月报。
