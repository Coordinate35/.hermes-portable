| 站点 | 可达 | 备注 |

**建议优先级**：苦瓜书盘 → 鸠摩搜书 → 其他（需要时再补）

## 苦瓜书盘下载流程（实测）

1. 搜索：`https://kgbook.com/`，用浏览器的 input 直接输入书名再点搜索
2. 列表页 → 进详情页 → 找到"格式"字段（常见 mobi/epub/azw3）
3. 下载链接形式：`https://kgbook.com/e/DownSys/GetDown?classid=2&id=<书id>&pathid=0`
4. curl 时**必须加 Referer 头**指向详情页，否则可能被拦
5. 服务器返回 301 → 302 → 实际 mobi 文件路径，curl `-L` 跟随即可

**示例命令**：
```bash
curl -s -L --max-time 60 \
  -A "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36" \
  -e "https://kgbook.com/wuxiaxiaoshuo/399.html" \
  "https://kgbook.com/e/DownSys/GetDown?classid=2&id=399&pathid=0" \
  -o /tmp/book.mobi
file /tmp/book.mobi  # 验证：Mobipocket E-book "<书名>", N bytes, version 6
```

## 金庸作品版本说明

金庸长篇有三个版本，质量/争议从老到新：

| 版本 | 年代 | 评价 | 网上易得性 |
|------|------|------|-----------|
| 旧版/连载版 | 1955-1972 报刊连载 | 稀有，研究价值高 | ❌ 难找 |
| **三联修订版** | 1980 年代修订 | **最经典，多数人读的就是这版** | ⚠️ 中等，需多源尝试 |
| 新修版/世纪新修版 | 2003 后改写 | 改了不少结局（黄药师梅超风感情、华筝结局等），有争议 | ✅ 苦瓜书盘等都有 |

**版本对用户体验的影响**：
- 前 30 回剧情几乎一样
- 主要差异在结局和部分感情线
- 听故事走流程 → 新修版没问题；要原汁原味 → 必须三联版

**导入时务必在 --version 字段标注清楚版本**，避免用户期望落空。

## HTML 在线阅读站（兜底方案）

当下载站找不到目标版本时，可用在线阅读站爬取：

| 站点 | 特点 | 适用场景 |
|------|------|---------|
| jinyongx.com | 金庸三版齐全：`/she/`=修订版(三联), `/nshe/`=新修版, `/oshe/`=旧版 | 金庸三联版兜底 |
| jinyong.net.cn | 修订版全文在线阅读 | 金庸三联版兜底 |

**爬取流程**（以 jinyongx.com 为例）：
1. 访问目录页，提取所有章节链接（如 `/she/159.html` ~ `/she/198.html`，编号不一定从 1 开始）
2. 逐页 curl + BeautifulSoup 提取正文（实测 class=`vcon` 或 class=`vertical` 是正文容器，取最大的 div 即可）
3. 合并成一个大 txt 文件，按章节标题正则切分
4. 用 `add_book.py --source <txt路径>` 导入
5. **请求间隔 ≥ 1.5 秒**，避免被限速/封 IP
6. **章节标题还原**：站方可能用"第X章"，纸质原版是"第X回"，导入前批量替换更贴近原文

**注意事项**：
- HTML 正文可能含广告/水印/站名，需清洗
- 章节编号不一定从第 1 章开始，需要建立 URL → 章节序号 的映射表
- 附录/后记（如"成吉思汗家族"、金庸"后记"）单独处理，可选导入或跳过
- 验证版本匹配：抓首章首段，跟纸质书已知开头比对（如射雕修订版开头是"钱塘江浩浩江水…"）

## 版权与免责声明

金庸作品在中国大陆受版权保护到 2068 年。免费下载属侵权下载。
合法替代：
- 微信读书（部分免费/会员）
- 京东读书、当当云阅读
- Kindle 商店（约 15-30 元/本）

**在帮用户下载前，应当先告知版权风险并让用户明确选择**（参考本次会话的处理方式）。
