# 微信长消息处理技能

## 触发条件

当需要向用户发送以下类型的内容时：
- 文章原文（如《掠过佛莱堡》等长文）
- 分析报告（超1000字）
- 多条微博/新闻摘要的批量发送
- 任何预计超过1000字符的消息

## 核心规则

1. **单条限制**：微信单条消息不要超过 **1500字符**（含标点、换行、空格）。
2. **分段发送**：长文必须分成多个短段逐条发送，不能一次性发完。
3. **段落完整性**：拆分时以自然段落/句子为界，不能在句子中间切断。
4. **标注序号**：在开头标注【续】或 【1/N】【2/N】，让用户知道还有后续内容。
5. **收尾确认**：发完后提示用户检查是否全部收到，如有遗漏可补发。

## 工作流程

### Step 1: 估算长度
在回复前先估算要发送的总字符数。如果超过1500，进入分段逻辑。

### Step 2: 分段策略
```
目标段长: 1200-1500字符
优先级: 段落 > 句子 > 行
避免: 在一个完整意思未表达完时切断
```

### Step 3: 逐段发送
每发一段后，检查下一段是否还有内容，然后继续发送。不要等到最后才发现超长了。

### Step 4: 结束确认
最后一段发完后，附一段话：
> “以上全部发完。请确认是否都收到了，有漏掉的话告诉我补发。”

## 实际案例

**案例一：发送一篇 5000 字的原文**
```
❌ 错误做法：直接一次性发送 5000 字的消息
✅ 正确做法：分成 4 段，每段 1200 字左右
  - 第1段：【1/4】标题 + 第一部分
  - 第2段：【2/4】第二部分
  - 第3段：【3/4】第三部分
  - 第4段：【4/4】结尾部分 + 确认提示
```

**案例二：补发遗漏段落**
用户反馈"请稍后再试"或某段没收到：
1. 立即承认："刚才消息被截断了，现在补发漏掉的部分"
2. 重发遗漏段，不需要重发已收到的

## 常见错误

1. 以为只有文件才会被截断，文本消息也会。
2. 估算长度时只算文字，忽略了 Markdown 格式符号、换行符也占字符数。
3. 切断在一个句子的中间，导致意思不连贯。
4. **假分段**：把多段内容写进同一条消息里用 `---` 分隔，这不是真正的分段，微信端仍然显示为一条超长消息。必须每段都是独立的 `send_message` 调用/独立回复回合。
5. **忽略截断提示**：用户收到"请稍后再试"而不是正文，这是消息被截断的典型表现，必须立即补发。

## 关键知识点

- **字符 vs 字数**：限制是字符（char），不是字数。1个汉字 = 1字符，1个字母也 = 1字符。
- **安全边界**：建议每段不要超过 1200 字符，留10%余量给格式化字符。
- **不是所有平台都一样**：此限制特指微信通道，其他平台（如 Telegram）可能容量更大。
