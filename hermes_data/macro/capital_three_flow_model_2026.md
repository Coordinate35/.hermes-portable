# 中美「三流」动态模型与流向逆转开关
**版本**：v1.0　**日期**：2026-11-12（数据截至 2026-11-13）　**框架**：卢麒元 资本三流（流量 / 流向 / 流速）

---

## 0. 一句话结论

> 模型的开关不是「中美利差转正」，而是**居民端持有外币资产的机会成本**：
> Φ_r = (r_us − r_cn) − E[Δs] − ρ_r ≤ 0。
> 当前 Φ_r ≈ **+2.0pp**（仍在流出）；股票端开关已提前打开（外资 Q2 持股单季 +9400 亿元），债券端未开。
> **净流向逆转的基准时间窗：2028Q3–2029Q1**；乐观（美联储快速转鸽/人民币破 6.5）2027Q4；悲观（通胀失控）2029H2 之后。
> 若发生美元信用事件，开关不是移动而是**跳变**，与利差路径无关。

---

## 1. 状态变量

| 符号 | 含义 | 单位 |
|---|---|---|
| M_t | 全球可跨境配置资本存量 | 万亿美元 |
| x_t | 配置于中国的份额 | — |
| v_t | 流速（组合调整速度，年⁻¹） | 1/年 |
| u_t | 政策阀门（资本管制开放度，0–1） | — |
| Ω_t | 风险调整后的预期超额收益 | 百分点 |

---

## 2. 三流方程组

**（1）流量**
```
dM/dt = g_M · M
g_M = w_us·g(M2_us) + w_cn·g(M2_cn)
```
代入：g(M2_us)=5.71%，g(M2_cn)=7.1%，w=(0.7,0.3) → g_M ≈ **6.1%/年**

**（2）流向**
```
dx/dt = v_t · [ σ(β·Ω_t) − x_t ]
σ(z) = 1 / (1 + e^(−z))
```
**（3）流速**
```
v_t = v_0 · u_t · (1 + κ·T_t)
```
T_t 为换手率（北向成交占 A 股 12.3%，债券通日均 435 亿元，2026 年 1–9 月）。

**净流入**
```
F_t = M_t · dx/dt = v_t · M_t · [ σ(β·Ω_t) − x_t ]
```

---

## 3. 开关的解析解

F = 0 等价于目标份额等于当前份额：

```
σ(β·Ω*) = x_t   ⟹   Ω*_k = (1/β_k) · ln( x_k / (1 − x_k) )
```

即：**开关不在 Ω=0，而在「低配阈值」Ω*<0**。中国资产被全球低配，所以即便超额收益为负，再平衡资金仍可流入——这正是 2026 年股票流入、债券流出的分叉原因。

**卢氏真实通胀**（CPI + M2 − GDP）：
```
π_cn = 0.7 + (7.1 − 4.6) = 3.20%
π_us = 3.9 + (5.71 − 5.87) = 3.74%
```
**实际利率**：
```
r_cn = 1.598 − 3.20 = −1.60%
r_us = 5.15 − 3.74 = +1.41%
实际利差（US−CN）= 3.01pp
```
> 若改用官方 CPI 口径，实际利差只有 0.35pp——两种口径差 2.7pp，这是所有「利差交易」判断的分水岭。

## 5. 三类资产分别开关

**债券**
```
Ω_b = (r_cn − r_us) + E[Δs] − ρ_b = 1.60 − 5.15 + 1.06 − 0.3 = −2.79pp
x_b ≈ 3%  ⟹  Ω*_b = (1/2)·ln(0.03/0.97) = −1.74pp
```
Ω_b < Ω*_b → **继续流出**。证据：境外持债由 2025-04 的 4.44 万亿降至 2026-09 的 3.19 万亿元；2026H1 境内对外债券投资 +1199 亿美元（同比 +1.9 倍）。

**股票**
```
Ω_e = (E/P_cn − E/P_us) + E[Δs] − ρ_e = (7.75 − 4.12) + 1.06 − 0.5 = +4.19pp
x_e ≈ 6%  ⟹  Ω*_e = (1/2)·ln(0.06/0.94) = −1.37pp
```
Ω_e ≫ Ω*_e → **已流入**。证据：2026H1 外资来华股本证券 +537 亿美元（同比 +90%）；Q2 境外持有 A 股单季 +9400 亿元（有记录最大）；北向 Q1 净流入 3274 亿元。

**直接投资**：受政策与产业周期驱动，对利差不敏感，暂作外生项。

---

## 6. 主体分侧：为什么净额仍是流出

BOP 恒等式掩盖了结构。真正决定净额的是**居民端**：

```
Φ_r = (r_us − r_cn) − E[Δs] − ρ_r
    = 3.55 − 1.06 − 0.5 = +1.99pp   （正 = 继续流出）
```

2026 年前三季度：经常账户顺差 **6541 亿美元**（Q3 单季 2761 亿，创纪录），资本和金融账户逆差 **6213 亿美元**——贸易顺差被金融账户流出对冲掉，储备资产仅小幅变动。

**主开关**：
```
Φ_r ≤ 0  ⟺  (r_us − r_cn) ≤ E[Δs] + ρ_r ≈ 1.5pp
```
当前 3.55pp，需要再收敛 **约 2pp**。

---

## 7. 时间窗口

设 ρ_r=0.5pp，美联储路径为情景变量：

| 情景 | 2027H2 美10Y / 人民币预期 | Φ_r | 开关时点 |
|---|---|---|---|
| 乐观（衰退→快速降息） | 3.7% / +3.0% | −1.3 | **2027Q4** |
| 基准（2027 见顶 4.5%，2028 降息） | 4.8%→4.3% / +1.6→2.0% | +0.8→−0.1 | **2028Q3–2029Q1** |
| 悲观（通胀 5%+，Fed 加到 5%） | 5.8% / +1.0% | +2.3 | **2029H2 之后** |

**分层结论**：
1. **边际逆转（二阶导）**：2025Q4–2026Q2 已发生（股权端）。
2. **净流入转正（一阶导）**：基准 2028Q3–2029Q1。
3. **存量再配置（份额）**：2029–2032。

**跳变情形**：若美债拍卖失败/美元信用事件，ρ_us 跳升 200–300bp，Φ 不经过零而直接翻转，无日期可预测——这是卢麒元框架的主情景，但模型只能给出触发条件，不能给出日历时间。

## 8. 流速阀门（政策）

- 央行 11-15 将外汇存款准备金率由 4% 上调至 6%：这是** inflow 的刹车**，不是 outflow 的闸门。
- 含义：即使 Φ 转负，可视的流入速度仍会被 u_t 压低；「开关打开」≠「水立刻流进来」。
- 观测 u_t 的代理：外汇存款准备金率、远期售汇风险准备金、QDII 额度、跨境理财通额度。

## 9. 月度观测锚（按优先级）

1. 中美 10Y 利差（目标：≤1.5pp 为开关临界）
2. USD/CNY 与 1Y 掉期点（升值预期 ≥2.5%/年 为替代开关）
3. 结汇率 / 售汇率（居民端行为的最快读数）
4. 境外持有人民币债券（3.19 万亿 → 拐点）
5. 外资持有 A 股（季度，11.33 万亿总量的分项）
6. 国际收支金融账户（季度，是否由 −6213 亿转正）

---

## 10. 局限与诚实边界

- β、x_k、ρ 是**校准假设**，不是观测值；结论对 ρ_r 敏感（±0.5pp 可移动窗口 2–3 个季度）。
- 卢氏公式原为人民币体系设计，套用于美国 M2/GDP 是**外推**；用名义 GDP 与官方 CPI 两套口径的结论差 2.7pp，已在文中并列。
- BOP 数据为初步数，2026Q3 终值 12-30 公布，可能修正。
- 模型不预测危机，只描述条件；信用事件属外生跳变。
