# 宏观情景 → 公司定量压力测试（"链条法"）

**触发**：用户给定宏观情景（美元重置 / 油价飙升 / 恶性通胀 / 汇率冲击），问对某家具体公司的影响；
或明确要求"定量的假设分析"。**不要停在定性**——定性版之后用户会追加"具体展开定量"。

案例：高标科技 2026-09（美元重置+油价 $200-300），见 `gaobiao-case-2026.md`。

## 一、两个前置校验（必做）

1. **公司画像以披露口径为准**，不采信口头描述。
   例：高标被描述为"出口电动自行车电机企业"→ 实际 91.7% 营收为内销控制器（全球第一），
   电机（E-bike 电驱）仅 7.6%，境外收入占比 8.13%（快增但尚小）。
2. **情景数字定级**：把"油价 $200-300"类数字声明为**压力测试情景**，非基准。
   卢麒元口径参照：方向确认（金转油、价格必然上行），数值为转述且自评"有点过分/近妖"的预测。

## 二、五链条映射（情景 → 报表科目）

| # | 链条 | 报表科目 | 量化抓手 |
|---|------|---------|---------|
| 1 | 成本 | 主营业务成本-直接材料 | λ=材料/收入；招股书自带敏感性（材料±10%→毛利∓25%） |
| 2 | 传导率 k | 售价 | k=实际提价/所需提价；证据=历史年降/以价换量、客户集中度、产能利用率 |
| 3 | 需求 | 销量 | 替代效应 vs 购买力破坏；政策（新国标/以旧换新/关税退税） |
| 4 | 汇率 | 境外收入 | 外币收入占比 × 本币升贬；历史汇兑损益 |
| 5 | 资产负债表 | 应收/存货/现金/募投 | 存货/材料年耗=缓冲月数；票据回款=通胀损耗；崩盘市 IPO 发行风险 |

## 三、核心公式（通用恒等式）

- λ = 直接材料 ÷ 主营业务收入（提价负担杠杆比）
- 所需提价 ΔP_req = λ × m（m=材料涨幅）；实际提价 = k × ΔP_req
- 毛利变动 ΔG = −(1−k) × m × M0（M0=直接材料额）
- 双阈值（售价=基准×(1+k·ΔP_req)）：
  - 毛利归零 m* = G0 ÷ ((1−k)·M0)
  - 净利归零 m** = PBT ÷ ((1−k)·M0)（仅计毛利渠道）
- 单位换算：所需提价额 ÷ 产品均价 × 终端零售价 → 判断"物理传导空间"
- 名义≠实际：名义利润 ÷ (1+累计通胀)

## 四、产出物与交付约定（用户偏好）

1. **可重跑脚本**：`~/hermes_data/ipos/<公司简称>/scenario_model.py`
   （纯 python 无依赖；基准=最新实际；m/k/汇率/量/费用通胀参数集中可调；情景函数化）
2. **回复格式（必须展开过程）**：假设清单 → 公式 → 至少一个情景完整代入（→中间→结果） →
   全情景结果桥（收入/毛利/净利+拆解项）→ 反直觉量化点 → 假设边界 → 判断+观测锚。
   反例：只给"净利约降30%"式结论——会被用户要求重来。
3. **假设与数据分离**：外生假设逐条声明"是假设非预测"；公司数据标注来源版本与报告期。
4. **观测锚**：列出可跟踪指标（布伦特阈值/大宗价/汇率/运价/季度毛利率/调价函）。

## 五、坑

- 主营口径与合并口径不要混用：毛利率用主营，净利锚用合并。
- 亏损情景注明未计税盾递延、未计其他收益/投资收益缓冲。
- 量影响以毛利近似边际贡献——声明是近似。
- k 是最大未知数：下行传导有实证（行业中降价周期公司跟随），上行传导无样本——不要默认"能提价"。
- 存货缓冲上限 = 存货/材料年耗（月份）；结构未知时明确说"上限"。
- 保险做法：把"每 10% 材料敏感度、双阈值表、k 修复测试"都算出（用户偏好阈值与反事实）。
