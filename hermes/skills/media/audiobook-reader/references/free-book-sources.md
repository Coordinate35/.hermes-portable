# 免费电子书来源（实测可达性 + 搜索策略）

⚠️ 用户已知会"免费下载 = 侵权"的法律事实，并选择了 A 方案（自担风险）。本文档假设用户授权后再用。

## 可达性实测（2026-05-29，从 VirtualBox Linux 客户机直出，无代理）

| 来源 | URL | 状态 | 适合找什么 |
|---|---|:---:|---|
| **苦瓜书盘** | https://www.kgbook.com/ | ✅ HTTP 200 | 精排 epub/mobi，中文文学覆盖好；金庸常有但版本随机 |
| **鸠摩搜书** | https://www.jiumodiary.com/ | ✅ HTTP 200 | 全网聚合搜索（指向网盘链接），命中率高但需手动跳转网盘 |
| 书格 | https://www.shuge.org/ | ✅ HTTP 200 | 古籍/善本 PDF 为主，金庸这类近代小说覆盖少 |
| Anna's Archive (.org/.se/.li) | annas-archive.* | ❌ 三个域全部不通 | （理论上是首选，但无代理时不可用） |
| Z-Library (z-library.sk / 1lib.sk) | z-library.sk | ❌ 不通 | 同上 |

**实测命令**（复现用）：
```bash
for url in https://annas-archive.org/ https://z-library.sk/ https://www.kgbook.com/ https://www.jiumodiary.com/ https://www.shuge.org/; do
  echo "=== $url ==="; curl -sI --max-time 8 "$url" 2>&1 | head -2
done
```

## 搜索策略（按命中率排序）

1. **苦瓜书盘**：首页搜索框直接输书名 → 看搜索结果列表 → 进详情页找下载链接
   - URL 模式：站内搜索通过首页表单提交，**不要**直接拼 `/search.php?searchword=...`（实测 404）
2. **鸠摩搜书**：聚合搜索，结果通常指向网盘（百度网盘居多），需要手动登录网盘下载，自动化困难
3. **微信读书 / 京东读书**：合法路线，部分免费试读，金庸全集需会员

## 金庸作品版本辨识

| 版本 | 别名 | 年代 | 备注 |
|---|---|---|---|
| 旧版/连载版 | 报刊连载版 | 1955-1972 | 极稀有，几乎绝迹 |
| **修订版** | **三联版/明河版** | 1980 年代 | **最经典**，多数读者读的这版 |
| 新修版 | 世纪新修版/广州花城版 | 2003 后 | 改了结局，争议大（黄药师/华筝/王语嫣线变动） |

**辨识技巧**：
- 标题带【新修版】【世纪新修版】= 2003 后版本
- 标题不带后缀且封面是三联出版社 = 三联修订版
- 苦瓜书盘的金庸资源**多为新修版**，三联版在国内站点较难找到，需要通过有代理时的 Anna's Archive 或老资源站

## 降级策略（找不到指定版本时）

不要默默用替代版本！按以下顺序处理：
1. 回报用户："只找到 X 版本，没有你要的 Y 版本"
2. 说明版本差异（如三联 vs 新修结局不同）
3. 给方案 A/B：A 用替代版跑通 + 后续覆盖；B 等用户去找原版资源
4. 用户拍板后再 `add_book.py --force`

## 不要做的事

- ❌ 不要凭直觉一直试 Anna's Archive / Z-Library —— 在当前无代理环境下三个域全部不通，浪费时间。如果未来用户配了代理或换了网络，再重新测一遍这张表
- ❌ 不要在国内站点（苦瓜/鸠摩）默认能找到三联修订版——以新修版居多
- ❌ 不要直接拼苦瓜书盘的 `/search.php?searchword=` URL（404），用首页搜索表单
