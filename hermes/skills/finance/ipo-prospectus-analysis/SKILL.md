# IPO 招股书查找与财务分析

用户投资分析场景高频任务：找招股书 + 主营业务/资产负债表/现金流总结分析。

## When to Use

命中即用，无论措辞如何变化：
- 找/查/搜/下载 IPO 招股书、招股说明书、上市文件、上市保荐书、注册稿
- "帮我分析 XX 公司 / 这家公司怎么样 / 给我总结一下招股书 / 财报 / 年报"
- 上市前公司（已受理/已问询/已注册）的基本面与财务数据核查
- 用户提到具体公司名 + IPO/上市/招股/募资/财务/营收/利润/现金流之一

## 一、查找与下载

1. **确认公司全称/板块**：搜索 `"<公司名> 招股说明书"`。注意简称可能有歧义（如"高标科技"=广东高标智能科技），以招股书首页全称为准；记录：板块（沪深北/创业板/科创板）、受理日期、保荐机构。
2. **官方 PDF 直链**：
   - 深交所披露文件静态站：`site:reportdocs.static.szse.cn <公司名>` 搜到的 URL 即为官方 PDF 直链（`http://reportdocs.static.szse.cn/UpFiles/rasinfodisc1/<YYYYMM>/...pdf`）。
   - 同一批申报文件（上市保荐书、发行保荐书、法律意见书）通常在同一日期目录，按同 URL 模式搜即可。
   - 巨潮资讯网 cninfo.com.cn 为 A 股法定披露平台，可用于检索。
3. **下载**：QQ Bot 远程会话中 terminal 前台命令可能触发权限确认并超时拒绝（即使文件下载这种无害操作）。可靠做法：`background=true` + `notify=["...DONE"]`，命令末尾 echo 匹配 pattern；完成后单独跑 `ls -lh` + `file *.pdf` 验证页数，`head -c 8 *.pdf | xxd` 确认 `%PDF` 头。
4. **版本标注**：招股书分申报稿/上会稿/注册稿/正式版；受理稿非最终版，问询阶段后可能更新。交付时明确标注版本与披露日期。

## 二、文本提取与章节定位

```bash
cd <path> && pdftotext -layout 招股说明书.pdf 招股说明书.txt
wc -lc 招股说明书.txt
grep -n "第[一二三四五六七八九十]节" 招股说明书.txt | head -40
```

常用章节定位 grep 关键词（都命中才算读全面）：
- 概览/财务摘要：`主要财务数据及财务指标`、`募集资金运用`
- 主营业务：`主营业务情况`、`主营业务收入构成`、`主要产品`、`主要经营模式`
- 报表：`合并资产负债表`、`合并利润表`、`合并现金流量表`、`审计意见及关键审计事项`
- 分析：`主营业务毛利率`、`分产品`、`前五大客户`、`产能利用率`、`应收账款周转率`、`存货周转率`、`经营活动产生的现金流量净额`、`现金及现金等价物净增加额`
- 风险：`风险因素`

## 三、财务指标测算（代入数值，展开过程）

- 营收/净利 CAGR、毛利率（主营 vs 综合）
- **净现比 = 经营活动现金流净额 / 净利润**（健康 >80%；<30% 是利润质量警示）
- **收现比 = 销售商品收现 / 营业收入**（<70% 提示回款靠赊销/票据）
- 流动比率、速动比率、资产负债率（合并口径）
- 客户/供应商集中度（前五大占比）、产能利用率、产销率
- 现金+理财：货币资金 + 交易性金融资产 + 债权投资 + 一年内到期非流动资产（表观货币资金低 ≠ 没钱）

## 四、输出结构（用户偏好：过程展开、数据标报告期）

公司概况 → 主营业务（产品矩阵/市占率/客户/量价/海外占比）→ 资产负债表要点 → 利润与现金流（重点：净现比背离与原因：应收、票据回款、存货）→ 产能与募投 → 研发占比趋势 → 风险清单 → 总体评价（亮点/疑点/核心判断）。

## 五、Pitfalls

- 经营现金流与净利润背离是制造企业快速上量期常见问题：客户大量用银行承兑汇票回款（应收票据/应收款项融资激增）、应收账款随收入同步膨胀。票据回款金额在"发行人重要客户以现金、银行转账以外方式回款情况"表里。
- 政策红利驱动的高增长（新国标/以旧换新/购置补贴）可持续性存疑，必须提示。
- 中置系统第二曲线早期往往产销率低（产量>销量，库存积压）但毛利率爬坡转正，属导入期特征而非暴雷。
- 上市前大额分红 + 大额理财存款 = 公司不缺现金，但表观经营现金流难看。
- web_extract 提取 PDF 可能因后端故障失败；本地 pdftotext 才是正路。
