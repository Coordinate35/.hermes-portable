# 游戏知识问答（宝可梦 / ROM 改版等）

用户会随口问游戏问题（当前在玩《漆黑的魅影》，可能延伸到其他游戏）。核心原则：**区分原版确定数据与改版特有声明，答不实的地方显式 hedge，不编造**。

## 触发条件

- "XX厉害吗 / 强吗 / 好用吗"（强度、种族值、实战评价）
- "XX在哪 / 怎么抓 / 怎么获得 / 怎么进化"
- "XX有什么说法 / 剧情 / 来历 / 传说"
- 任何游戏机制、设定、lore 提问

## 核心流程

1. **判断问题类型**（这一步决定验证预算）：
   - 原版游戏设定（种族值、机制、剧情传说）→ 凭确定知识直接答，数值如实报出。
   - 改版/Mod 特有声明（是否 buff、新增事件、地图改动）→ 默认「基本沿用原版设定」+ 显式 hedge，除非在线核实成功。
2. **web 验证预算（2-3 次封顶）**：只有改版特有声明才值得搜索。本环境中文搜索经常失败（Bing 结果污染、Baidu 验证码、Sogou 反爬、Google/DDG 超时）。**两次失败就停，转第 3 步降级作答**——不要烧 7 次调用，边际收益为零。
3. **降级作答**：基于原版确定知识回答，在语音/文字里显式区分来源：「这是原版绿宝石的设定」/「漆黑的魅影基本沿用，但我没能在线核实」。核心数据（如种族值总和）可以直接断言。
4. **交付**：QQ Bot 短句默认走语音，规则见 voice-message-delivery skill（三级降级链 + MEDIA 独占整条回复）。口播数字用中文（四百二十，不用 420）。

## 坑

- ❌ 把「改版没改」说成确定事实。无法验证时用「基本沿用原版数据」这种 hedge，别写「没有强化」的断言。
- ❌ 编造改版特有内容（专属事件、修改数值、特殊地图）——不确定就明说不知道。
- ❌ 在搜索引擎上无限重试。本环境中文搜索大概率失败，2 次失败即降级。
- ❌ 把阿拉伯数字直接塞给 TTS（如"420"）——口播稿用中文数字。
