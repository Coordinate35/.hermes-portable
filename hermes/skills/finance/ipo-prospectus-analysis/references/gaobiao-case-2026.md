## 本次应用的方法要点

搜索时用 `site:reportdocs.static.szse.cn <公司名>` 一次拿到招股书+保荐书全套直链；下载走 background+notify（前台被终端确认超时拦截两次）；`pdftotext -layout` 提取后 grep 定位第 X 节/三张报表/毛利率/前五大客户/产能利用率；分析按"概览财务→业务量价→资产负债表→利润与现金流背离→产能募投→风险→评价"输出。

## 2026-09-15 追加：宏观情景压力测试（美元重置 + 油价 $200-300 + 恶性通胀）

用户要求"定量假设分析"。建立可重跑模型：`~/hermes_data/ipos/gaobiao/scenario_model.py`（基准=2025实际，参数 m/k/汇率/量/费用通胀 可调）。方法论见 `macro-scenario-stress-test.md`。

### 模型输入（招股书原文定位，2025 口径）
- 成本构成（约 L10383 起）：直接材料 127,224.91 万/82.22%；直接人工 8,813.78/5.70%；制造费用 15,976.89/10.33%；售后 2,723.90/1.76%；合计 154,739.48 万
- 合并利润表（约 L8009 起）：营业收入 20.71 亿；营业成本 15.63 亿；销售 5,854.75 万；管理 13,468.29 万；研发 8,937.72 万；财务 474.60 万（期间费用合计 2.87 亿 / 13.87%）；利润总额 2.076 亿；净利 1.817 亿；归母 1.831 亿（有效税率 12.45%）
- 主营（约 L851/L4685）：主营收入 205,189.07 万、主营成本 154,739.48 万 → 毛利 5.04 亿（24.59%）
- 境外收入 1.668 亿 / 8.13%（欧元、美元结算）；汇兑损益仅 76 万
- 原材料价格敏感性（约 L1530）：材料 ±10% → 主营成本 ±8.2%、主营毛利 ∓25.2%（2025）

### 模型结论（2025 基准）
- λ = 材料/主营收入 = 62.0%（每 1% 材料通胀 ≈ 需 0.62% 提价对冲）
- ΔG = −(1−k)·m·12.72 亿；双阈值：m* = 39.7%/(1−k)（毛利归零）、m** = 16.3%/(1−k)（净利归零，仅毛利渠道）
- 材料每 +10% → 净利 −61%(k=0) / −31%(k=0.5) / −18%(k=0.7)
- 情景：S1 温和（m=25%, k=.65）净利 0.52 亿(−71%)；S2 压力（m=45%, k=.50）亏 1.56 亿；S3 恶性（m=70%, k=.45；2026-09-16 修订：汇率升至30%≈1:5，锚：现汇≈6.7、2025中枢≈7.2）亏 4.19 亿、极端 k*≈0.99；S2 下 k→0.8 即打平（−0.06 亿）
- 单位经济：m=45% 需提价 27.9% = +12.6 元/台（45.23 元基准）= 整车零售价(~2500元)的 0.50% → 物理传导空间存在
- 存货缓冲：3.31 亿 / 材料年耗 12.72 亿 = 26%（≈3.1 个月上限）
- k 的实证参照：2024 年行业以价换量，公司均价 −6.46% 跟随（下行传导有样本，上行无样本）
