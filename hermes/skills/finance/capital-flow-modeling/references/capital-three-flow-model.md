# 资本三流模型：标定清单与情景模板

## 1. 状态变量与取值口径

| 符号 | 含义 | 取值方式 |
|---|---|---|
| M_t | 可跨境配置资本 | 中美 M2 加权：`w_us·M2_us + w_cn·M2_cn`，权重可按股债规模 |
| x_t | 配置于中国的份额 | 外资持股/持债 ÷ 该市场总市值（或全球组合） |
| v_t | 流速 | 成交额/市值、跨境人民币收付增速、债券通日均成交 |
| u_t | 政策阀门 | 外汇存款准备金率、远期售汇风险准备金、QDII 额度作代理 |

## 2. 方程组与含义

```
dM/dt = g_M·M                      # 总流量：货币扩张决定可配置资本池
dx/dt = v·[σ(βΩ) − x]              # 流向：向目标份额调整，v 决定多快
v     = v0·u·(1+κT)                # 流速：制度与管制决定调整速度
F     = M·dx/dt                    # 净流入（对时间的导数）
```

- β 越大 → 对收益差越敏感（美国机构化市场 β 高；A 股外资占比低，β 低）。
- v 决定“开关打开后多快见效”，与制度基础设施（T+1/T+2、清算、互联互通）相关。

## 3. 开关推导

净流入为零时目标份额等于当前份额：

```
σ(βΩ*) = x
Ω* = (1/β)·ln[x/(1−x)]
```

数值直觉（β=2）：x=3% → Ω*≈−1.7pp；x=6% → −1.4pp；x=15% → −0.9pp。
即**低配越深，能容忍的超额收益越负**。这解释了为何在利差极度不利时，股票仍可能净流入，而债券继续流出。

## 4. 分资产 Ω

```
债券：Ω_b = (r_cn − r_us) + E[Δs] − ρ_b
股票：Ω_e = (E/P_cn − E/P_us) + E[Δs] − ρ_e     （可加盈利增速差）
```

对照观测做校准：
- 若 Ω_b < Ω*_b 而观测为持续减持 → 模型自洽；
- 若 Ω_e > Ω*_e 而观测为增持 → 自洽；
- 两者不一致时优先怀疑 ρ 设定与 x 的取数，而不是改公式。

## 5. 居民端主开关

```
Φ_r = (r_us − r_cn) − E[Δs] − ρ_r
```

ρ_r 为居民持有外币资产的摩擦（额度、税、汇兑成本），常用 0.3–0.7pp；须标注为假设。Φ_r>0 → 继续流出；求 `Φ_r(t*)=0` 得时间窗。

## 6. 情景模板

| 情景 | 假设 | 输出 |
|---|---|---|
| 乐观 | 衰退→快速降息，美 10Y 快速下行、汇率升值预期抬升 | 窗口最早，给季度 |
| 基准 | 加息见顶→次年降息，实际利率缓降 | 中间，给区间 ±2 季度 |
| 悲观 | 通胀失控继续加息，利差扩大 | 推迟，给“不早于” |
| 跳变 | 美债/美元信用事件，ρ_us 跳升 | 无日期，只给触发条件 |

每个情景必须写明：美 10Y、中 10Y、汇率预期三个输入，以及算出的 Φ。

## 7. 观测锚

1. 中美 10Y 利差（开关临界的直接读数）
2. 即期汇率与 1Y 掉期点/远期（升值预期的市场价）
3. 结汇率/售汇率（居民行为最快代理）
4. 境外持债、外资持股市值（分项流量）
5. SAFE 金融账户与证券投资分项（季度，验证净额方向）
6. 政策阀门变动（外汇存款准备金率等）

## 8. 常见错误

- 把经常账户顺差当作资本流入：BOP 恒等式下两者互为镜像。
- 只用净额下结论：必须先看 gross flows 的两侧谁在动。
- 汇率预期用即期年化涨幅代替：那是已实现升值，不是预期；用远期/NDF 或调查预测。
- 把政策放松当转折：额度与准备金率调的是流速，不是收益差。
- 忘记标注数据时点：利差与汇率必须同一时点，跨日会引入噪声。
